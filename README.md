# /unsocial bot

a custom discord bot made for the /unsocial server.

## features
- welcome & goodbye messages
- ticket system (support, report, ban appeal)
- xp & leveling system
- moderation (kick, ban, mute, warn, purge)
- anti-raid & anti-spam protection
- alt account detection
- auto role on join
- bump reminders
- suggestions forum
- server & user info commands

## commands
prefix: `,`

| command | description |
|---|---|
| `,help` | shows all commands |
| `,rank` | shows your xp and level |
| `,leaderboard` | top 10 most active members |
| `,suggest <idea>` | submit a suggestion |
| `,remindme <time> <msg>` | set a reminder |
| `,ticket` | open a support ticket |
| `,userinfo` | info about a user |
| `,serverinfo` | info about the server |
| `,avatar` | shows a user's avatar |

## setup
1. clone the repo
2. run `npm install`
3. create a `.env` file with your bot token and channel IDs
4. run `node index.js`
